# APTE 삽입문 글꼴 복구

2026-11-03 사용자가 추적 삽입문의 글꼴 불일치를 지적하여 원본 문맥별 서식을 복구하였다. 본문은 #신명조·Times New Roman이며, 제목·표·캡션·인용·참고문헌의 원래 서식 구분을 유지하였다. 문단 앞 공백의 글꼴을 새 문장 전체에 상속한 것이 원인이었다.

## 복구 정책

- 본문 삽입72/53/62/63을 기존47로 복구하고 새 표 주석의 회색도 검정으로 맞췄다.
- 표2의 새 삽입46은 크기·색·자간·영어TNR을 보존한77을 사용해 한글 지정만 #신명조로 정리했다. 원래46의 영어가 잘못되었다는 판정은 아니다.
- 신규15/16번 참고문헌의 국문76자/6자는 원래70으로 복원했다. 동일 삽입 범위540/542가65/70/65 run을 가로지르므로 추적 상태를 section 전체에서 유지한다.
- 기존·삭제 글자와 원래77개 문자서식·글꼴표는 보존했다. 모든 삽입문의 한글/Latin 지정에서 맑은 고딕·함초롬바탕이 제외되었다. 초록의 미사용 한자·일어 등 다른 문자 영역과 원본 메모의 지정은 그대로다.

## 검증

기존 run54개 안의 삽입범위56개를 교정했다. 내용과 추적마커592개, 메모13개, 수식24개, 그림5개, 표6개, Table1 숫자176개는 보존되었다. 독립 파서로 거부 투영의 원본 문자·서식 복원과 복구 전후 수용·거부 텍스트 동일성을 확인했다. 한글17쪽을 새로 출력하여 전체 지면을 검토하고 최종 파일을 재열기했다.

일부 명조 글꼴은 PDF에서 윤곽선으로 출력되어 텍스트 추출만으로 보존을 판단할 수 없다. XML 문자·서식과 실제 페이지 표시를 함께 검증한다. 앱은 구독 상태상 읽기전용이므로 글꼴 편집 후 저장 및 변경 수용·거부·재저장 UI는 미시험이다.

현재 파일·SHA는 [[apte-source-register]], 검증 기록은 [[apte-validation-log]], 작업 범위는 [[apte-revision-hub]]를 따른다. 공개 근거는 [글꼴 복구 검토 기록](../docs/paper/revisions/2026-11-02/글꼴복구검토기록.md)과 [검증 JSON](../docs/paper/revisions/2026-11-02/evidence/글꼴복구검증결과.json)에 있다.
