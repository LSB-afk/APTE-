# 수정 결정 기록

[[apte-revision-hub]] · [[apte-professor-memos]] · [[apte-validation-log]]

## D001 원본 보존

원본 HWPX 의 해시를 등록하고 별도 수정본을 작성한다. 기존 메모를 보존한다.

## D002 변경내용 추적

사용자가 실제 변경내용 추적을 요청했다. 단순 색상 표시나 취소선을 추적 기능으로 대체하지 않는다. HWPX 의 추적 지원을 먼저 확인하고, 형식 변경이 필요하면 변환 충실도를 검증한다. 추적 형식의 검증이 실패한 파일을 완료본으로 전달하지 않는다.

## D003 미검증 결과

SMOTEN 성능, 전처리 범주 오류, 기준범주 해석, 반올림 원시값, 참고문헌 접근 제한 등은 별도 검토표로 관리한다. 저장 결과의 수치와 논문 해석의 타당성을 구분한다.

## D004 문체

수정 본문은 학술 논문 문체로 통일한다. 구어체, 근거 없는 인과 표현, 검증되지 않은 우월성 주장을 추가하지 않는다.

## D005 검증 후 상태 갱신

원문 대조 → 근거 확인 → 추적 수정 → 구조 검증 → 렌더링·시각 검토 → 독립 재검토 순서로 수행하고 매 단계의 결과를 기록한다. 미해결 항목이 있으면 완벽·최종 확정으로 표현하지 않는다.


## D006 결과를 바꾸지 않는 반복 확인과 반올림

기존자료·71 더미 설계를 고정한 LR/Poisson→고정αNB 및 단일 interaction 만 반복 적합했다. 원 pseudo R².1484638717 은 .148 로, 원 상호작용계수−.9345008795 는−.935 로 직접 반올림한다. 이전의 “반올림 원시값 보류”는 이 두 값에 대해 해소되었다. SMOTEN6 개 지표 생성 근거, Fig.2 전체 SHAP 배열 재계산, 문헌 원 28/29 의 원문 위치는 별도 한계로 남긴다.

## D007 원문 메모와 저자 판단

section1 메모 4 를 포함해 교수 메모는 13 개이며 원문을 모두 보존한다. 메모 9 의 검토중 문구와 메모 13 의 연구 방향 확인을 작성자 최종 승인으로 바꾸지 않는다. 메모 1 의 제목 3 안 우선순위는 보고서 제안으로 제시한다. 메모 7의 그림은 실제 이동하지 않았고 OR 설명 다음 쪽 상단 배치를 최종 출력에서 확인했다.

## D008 Mac 한글의 마지막 문단끝 보존

section1 마지막 필수 문단끝을 paraend=1 로 삭제 추적하면 현재 Mac 한글이 응답하지 않는 현상을 단일 경계 실험으로 격리했다. 그 끝 하나만 paraend=0 으로 보존한 파일은 정상 열리고 17 쪽 PDF 를 출력했다. 다른 새 문단과 앞선 문헌 삭제의 문단끝 추적은 유지한다. 모든 paraend 를 0 으로 바꾼 시험본을 최종본으로 사용하지 않았다. 구조 검사 통과와 실제 앱 호환성을 구분한다.

## D009 최신 산출물과 검증 상태

현재 수정본은 174 개 본문·표·인용 논리 변경+31 개 빈 문단 native 삭제=205 개 논리 변경·592 개 추적 범위다. 과거 559 범위 구조 보고서는 이전 시점 기록이며 최신 수치는 [파일식별정보](../docs/paper/revisions/2026-11-02/evidence/파일식별정보.json)와 [문서검증결과](../docs/paper/revisions/2026-11-02/evidence/문서검증결과.json)을 따른다. 한글 열기·17 쪽 PDF 출력 성공, 최종 17쪽 페이지 검토 통과, 읽기전용 제한으로 native 수용·거부 UI 미시험이다. ## D010 미리보기와 본문 변경의 구분

최종 한글 출력과 수용 텍스트로 Preview 캐시 및 content.hpf 메타를 갱신했다. 본문·추적 XML 3개는 캐시 갱신 전후 바이트 동일하며 전체 패키지 변경은 6개다. 오래된 미리보기 보류는 해소되었고 최종 17쪽 시각 검토·재열기를 통과했다. 앱 수용·거부 UI 미시험, SMOTEN·SHAP·문헌 원문 위치 한계는 별도로 유지한다.
