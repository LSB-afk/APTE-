## 출력 검증의 한계

최종 HWPX에서 원문 복원·서식·추적·메모·수식·그림·표의 독립 구조검증159항목을 통과하였다. 인용 순서와 서론 밖 문헌 정체성도 별도로 대조하였다.

이번에는 화면 제어 도구의 `failed to write kernel assets` 오류가 반복되고 연결된 document-control 세션도 없어 한글 재열기·새 PDF 출력을 확인하지 못하였다. [기존17쪽 PDF](APTE_전수재검토_검토용.pdf)는2026-11-03 직전본의 출력이며 **이번에 복원한 서론이 들어 있는 PDF가 아니다.** 현재 쪽수·줄바꿈·페이지 배치는 새 출력으로 검증하지 않았다. HWPX의 텍스트 미리보기는 현재 수용 본문으로 갱신했으나, 내장 첫 페이지 이미지는 직전본 캐시다. 실제 편집기의 수용·거부·재저장 UI도 미시험이다.
