# 참고문헌 검증표

검토일: 2026-11-02. 대상은 같은 폴더의 `APTE_교수메모반영_변경내용추적.hwpx`이다. 전체 수정 사항과 데이터·분석의 확인 범위는 [수정 검토 보고서](수정검토보고서.md)를 참조한다.

기존 참고문헌 29편 중 수정 본문에서 인용한 **22편을 첫 등장 순서로 재배열**하고, 사용하지 않은 7편은 변경내용 추적으로 제외하였다. 원번호는 수정 전 번호, 신번호는 수정본 번호이다. 이 표는 최종 수용 텍스트와 문서 생성 메타데이터의 번호 매핑을 대조하여 작성하였다. 최종 HWPX의 식별 SHA-256은 `1ac7621aa5ea69cc1572a24c4906021a110a77ad79cd1aa45828fb2c5754a965`이다.

**검증 범위:** “전문 열람”은 해당 원논문을 열람하고 연결한 주장과 서지를 확인했다는 뜻이며, 논문 안의 모든 문장·수식·데이터를 재검증했다는 의미가 아니다. 출판사 초록·서지·목차만 확인한 경우에는 그 수준을 구분하였다. 22편 전체의 출판본 전문 검증을 완료한 것으로 표시하지 않는다.

## 남은 확인 한계

1. **원28→신20:** Cameron과 Trivedi(1986)의 서지와 계수자료 모형의 범위는 확인하였다. 본 연구에서 사용한 포아송 적합값 기반 alpha 모멘트 추정식이 해당 원문 어느 식·쪽에 직접 제시되어 있는지는 확인하지 못하였다. 코드 및 회귀 재적합으로 계산 절차와 alpha=3.433832813…을 확인한 사실을 문헌의 특정 수식 출전 확인과 혼동하지 않는다.
2. **원29→신22:** McFadden(1980)의 저자·제목·발행 호·S13~S29는 확인하였다. 해당 문헌에서 pseudo R²를 정의한 정확한 위치·쪽수는 전문 접근 제한으로 확인하지 못하였다. 회귀 재적합에서 구한 0.148463871…을 0.148로 직접 반올림한 결과와 이 서지적 한계는 별개이다.
3. **원10→신10:** 저자 공개 원고는 확인하였고 785~794쪽은 ACM 공식 서지 검색 결과와 일치한다. ACM 출판본 전문은 접근 제한으로 열람하지 못하였으므로 “ACM 전문 검증 완료”로 기록하지 않는다.
