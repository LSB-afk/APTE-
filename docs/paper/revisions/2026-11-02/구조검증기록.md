## 실제 앱 검증과 증거 범위

주 작업자는 캐시 갱신 전의 동일 본문 XML을 한글에서 열어 전체 17쪽을 출력하였으며, 캐시 갱신 후 최종 파일을 다시 열어 첫 페이지와 전체 17쪽의 쪽수 표시가 정상적임을 확인했다고 보고하였다. 독립 검토에서는 해당 출력 PDF인 `revised-vif-verified.pdf`가 17쪽임을 직접 확인하고, 그 첫 페이지와 최종 HWPX 미리보기 이미지의 일치를 검증하였다. 캐시 갱신 스크립트는 갱신 전후 header·section0·section1의 해시 일치를 검사하며, 생성 기록에도 이 검사의 통과가 남아 있다.

이 기록의 XML 구조·객체 보존·텍스트 투영·캐시 대조는 독립 검토자가 직접 수행한 검사이다. 실제 한글 UI 열기·인쇄·페이지 표시 확인은 주 작업자의 관측이며, 독립 검토자가 직접 수행한 UI 시험으로 표시하지 않는다.

## 검증의 한계

현재 한글의 구독 상태가 읽기전용이므로, 실제 편집기의 변경 수용·거부 및 재저장 동작은 시험하지 못하였다. 위의 변경 거부 본문 일치는 XML에서 삽입을 제외하고 삭제 내용을 복원한 텍스트 투영 검사이며, 실제 앱의 수용·거부 기능 시험과 구분한다. 구조 검증은 한컴 공개 OWPML 모델의 추적 요소·속성과 일치함을 확인한 것이며, 별도 정식 XSD 적합성 검사로 표시하지 않는다.

또한 구조 검증은 문헌의 실질적 적합성이나 모든 분석 결과의 재현성을 대신하지 않는다. 데이터·분석 근거의 미확인 항목은 별도 검토 목록에 따른다.
