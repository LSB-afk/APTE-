## 실제 앱 검증과 증거 범위

2026-11-03 글꼴 복구본을 주 작업자가 한글에서 열어 `font-corrected.pdf` 17쪽으로 출력하였다. 주 작업자는 1~7쪽, 독립 검토자는 8~17쪽을 직접 표시하여 시각 검토하였다. 최종 미리보기·수정일 갱신 전후 header·section0·section1의 해시가 같고, 갱신 후 파일의 재열기 및 1/17쪽 표시도 확인하였다. 새 미리보기 이미지는 이 출력의 첫 쪽에서 생성하였다. 앞선 2026-11-02 출력은 글꼴 복구 전의 별도 스냅샷이다.

별도 독립 파서가 수용·거부 텍스트 동일성, 기존·삭제 문자의 문자별 서식 불변, 원본 거부 투영의 문자·서식 일치, 592개 추적 범위 및 객체 보존을 확인하였다. 국문 참고문헌의 같은 삽입 범위가 여러 run에 걸치므로 section 전체에서 추적 상태를 유지하였다. 원래 77개 문자 서식은 그대로 두고 표 2 삽입문 전용 서식 1개만 추가하였다. 자세한 범위와 한계는 [글꼴 복구 검토 기록](글꼴복구검토기록.md) 및 [검증 JSON](evidence/글꼴복구검증결과.json)에 명시하였다.

실제 한글 UI 열기·인쇄·페이지 표시 확인은 주 작업자의 관측이며, 독립 검토자가 직접 수행한 UI 시험으로 표시하지 않는다.

## 검증의 한계

현재 한글의 구독 상태가 읽기전용이므로, 실제 편집기의 변경 수용·거부 및 재저장 동작은 시험하지 못하였다. 위의 변경 거부 본문 일치는 XML에서 삽입을 제외하고 삭제 내용을 복원한 텍스트 투영 검사이며, 실제 앱의 수용·거부 기능 시험과 구분한다. 구조 검증은 한컴 공개 OWPML 모델의 추적 요소·속성과 일치함을 확인한 것이며, 별도 정식 XSD 적합성 검사로 표시하지 않는다.

또한 구조 검증은 문헌의 실질적 적합성이나 모든 분석 결과의 재현성을 대신하지 않는다. 데이터·분석 근거의 미확인 항목은 별도 검토 목록에 따른다.

**판정: 최종 해시의 HWPX에 대한 독립 구조 검증을 통과하였다. 실제 앱의 변경 수용·거부와 재저장 기능 검증은 미실시 상태로 남는다.**
