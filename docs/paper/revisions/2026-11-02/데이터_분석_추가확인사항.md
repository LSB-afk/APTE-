# 데이터·분석 추가 확인사항

기준일: 2026-11-02. 이 목록은 문안 수정 완료 여부와 분석 근거의 확인 여부를 분리하기 위한 기록이다. 확인되지 않은 수치를 새로 추정하여 논문에 채우지 않았다. [수정 검토 보고서](수정검토보고서.md), [참고문헌 검증표](참고문헌검증표.md)를 함께 참조한다.

## 2. 기존 분석의 해석 한계와 후속 분석

다음은 문장 교정만으로 해소되는 문제가 아니다. 원고에는 한계를 명시했으며, 이번 작업에서 표본·코딩·변수 선별을 바꾸어 새로운 연구 결과로 대체하지 않았다.

- **성토 범주 병합:** 기존 가공값의 ‘15m 이상’은 실제로 5m 이상 통합이다. 보고 명칭을 정정하였으며, 원래 높이별 차이는 범주를 재구성한 민감도 분석이 필요하다.
- **포트홀 기준 코딩:** 986행 유지와 더미 열 제거로 과속과 포트홀이 같은 기준효과에 포함된다. 분리 추정 방법 또는 범주 정의를 재검토하면 전체 회귀·상호작용 결과도 함께 재계산해야 한다.
- **변수 선별과 평가자료 사용:** 전체 자료의 타겟 연관성으로 변수를 선별했고, 불균형 모형의 임계값 0.61은 평가자료에서 선택하였다. 예측 성능은 이 조건을 전제로 해석한다.
- **탐색과 검정 관측치의 중복:** 24개 후보의 BH 보정만으로 선택 후 추론 문제나 독립 표본 재현성이 해소되지 않는다. 독립 검정 표본 또는 별도 설계가 필요하다.
- **분석 대상:** 기록된 사고 내 인명피해 비율을 분석했으며, 교통노출과 무사고 구간을 포함하지 않았다. 사고 발생 위험·감속의 인과효과·안전대책의 개입 효과는 별도 설계가 필요하다.
- **원자료의 동일 중복행:** 전체 열이 동일한 추가 3행을 기존 분석과 같이 유지하였다. 83,297은 고유 사고가 확정된 수가 아니라 분석에 사용한 기록 수다.

## 3. 본문에서 제외한 SHAP 수치의 보관 근거

아래는 기존 `interaction_profile.csv`의 `rankA_mean_abs`와 `rankB_per_occurrence`에 저장된 별도 상호작용 집계값이다. 일반 SHAP 분포인 Fig. 2에서 이 수치들을 직접 읽을 수 없으므로 본문에서는 제외하였다. 원자료나 관측치별 SHAP을 공개한 표가 아니다.

| 지표 | 조합 | 원문 표시값 |
|---|---|---:|
| A: 전체 추출 2,000건에서 평균 절대 상호작용 | 영업소–승용 | 0.025 |
| A | 주시태만–승용 | 0.022 |
| A | 주시태만–본선 | 0.019 |
| B: 동시 관측에서 대칭 성분 합산 평균 절대 상호작용 | 영업소–승용 | 0.286 |
| B | 노면잡물–조명시설 없음 | 0.193 |
| B | 주시태만–영업소 | 0.170 |

A와 B는 분모와 대칭 성분 합산 방식이 다르므로 크기를 같은 척도로 직접 비교하지 않는다. 실제 결과 파일은 [상호작용 집계](../../../../outputs/tables/shap_top_interactions.csv), [24개 회귀 검정 집계](../../../../outputs/tables/interaction_profile.csv), [방향 비교 집계](../../../../outputs/tables/shap_lr_direction_agreement.csv)이다.
