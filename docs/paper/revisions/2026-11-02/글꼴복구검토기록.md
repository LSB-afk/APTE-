# 변경 추적 삽입문의 글꼴 복구 기록

검증일: 2026년 11월 3일. 대상: [APTE_메모내용 반영_변경내용추적.hwpx](APTE_메모내용%20반영_변경내용추적.hwpx).

추적 삽입문을 원본의 본문·제목·표·캡션·참고문헌 서식과 대조하여 글꼴을 복구하였다. 본문은 한글 **#신명조**, 영문 **Times New Roman**을 적용하였다. 문안·분석 결과·추적 범위·교수 메모는 보존하였다.

## 원인과 복구 범위

일부 문단의 첫 run은 공백에만 지정된 서식이었다. 이 서식을 새 문장 전체에 상속하면서 #중고딕 또는 맑은 고딕이 적용되었다. 본문의 다른 삽입문에는 원래 문서의 혼합 영문 지정인 함초롬바탕이 남아 있었다. 참고문헌 재배열 과정에서는 국문 구간의 별도 글꼴이 평탄화되었다.

| 대상 | 복구 결과 |
|---|---|
| 본문 삽입문 | 원본 본문의 #신명조·Times New Roman, 10.3pt·장평 97%·자간 −4%에 맞춤 |
| 새 표 1·표 3 주석 | 공백의 서식을 배제하고 본문 서식 적용. 표 3 주석의 회색도 원래 본문 검정으로 복구 |
| 표 2 삽입문 | 영어 Times New Roman·8.5pt·색·자간 유지. 한글 영역 지정도 #신명조로 정리한 별도 문자 서식 사용 |
| 국문 참고문헌 | 새 15번 Moon의 국문 제목·학술지 76자, 새 16번 Ko의 학술지명 6자를 원래 #신명조 서식으로 복구 |
| 제목·소제목·영문 초록·캡션·표 1·위 첨자 인용 | 각각 원본 문맥의 글꼴·크기·위 첨자 유지 |

수정 대상은 기존 run 54개 안의 삽입 범위 56개이다. 이는 새로운 문안 수정 56건을 의미하지 않는다. 기존 592개 추적 범위 안에서 삽입문 서식을 바로잡았다. 기존 글자와 삭제 글자의 문자별 서식, 원래 77개 문자 서식 정의 및 언어별 글꼴표는 그대로 보존하였다. 표 2 전용 서식 하나만 추가하였다.

원래 표 2의 영어 자체는 Times New Roman이었다. 이번 표 2 조치는 새 삽입문의 다른 문자 영역 지정을 정리한 것으로, 영어가 맑은 고딕으로 출력되었다는 판정은 아니다. 파일 전체에 맑은 고딕·함초롬바탕 이름이 없어졌다는 뜻도 아니다. 기존·삭제 문자와 교수 메모, 초록의 미사용 한자·일어 등 원본 지정은 보존 대상이다. **모든 삽입문의 한글·Latin 지정에서는 맑은 고딕·함초롬바탕이 제외되었다.**

## 보존 검증

- 복구 전후 수용·거부 텍스트가 section 0·1 모두 동일하다.
- 거부 투영은 원본의 문자별 텍스트와 문자 서식에 일치한다. 문단 ID가 중복되므로 원본 순서와 중첩 위치로 대조하였다.
- 기존·삭제 문자의 문자별 서식은 복구 전과 동일하다.
- 추적 마커의 속성·순서·Id·TcId와 헤더의 추적 기록은 불변이다. 총 592개 범위는 삭제 318개·삽입 274개이다.
- 메모 13개, 수식 24개, 그림 5개 및 바이너리 5개, 표 격자 6개를 보존하였다. 표 1의 88개 항목·176개 수치·15개 집단 합계 검사를 다시 통과하였다.
- 문헌 최초 인용 순서 1~22, 미정의 인용 0개, 미인용 유지 문헌 0개를 다시 확인하였다.
- 두 국문 참고문헌은 같은 삽입 범위 안에서 65/70/65 문자 서식을 사용한다. 검증 파서는 run·t 경계를 넘어 begin부터 end까지 추적 상태를 유지한다.

## 실제 한글 출력과 검증 한계

macOS 한글에서 복구본을 정상적으로 열고 17쪽 PDF로 출력하였다. 주 작업자가 1~7쪽, 독립 검토자가 8~17쪽의 페이지 이미지를 직접 열어 글꼴·표·그림·캡션·쪽 경계를 확인하였다. 글꼴 복구에 따른 잘림·겹침·누락 글리프는 발견되지 않았다. 11쪽 표 3 주석은 검정색으로 출력되며, 16~17쪽 Moon 및 Ko의 국문은 명조체로 표시된다. 최종 캐시 갱신 후 파일도 재열기하여 첫 쪽과 1/17쪽 표시를 확인하였다.

일부 원래 명조 글꼴은 한글 PDF 출력에서 윤곽선으로 표현되어 텍스트 추출에 잡히지 않는다. 따라서 PDF 추출 문자열의 완전 일치를 판정 근거로 사용하지 않았으며, XML 문자·서식 보존과 페이지의 실제 글리프 표시를 함께 확인하였다.

설치된 한글 앱은 편집에 유료 구독이 필요한 읽기 전용 상태이다. **앱에서 글꼴을 직접 바꾼 뒤 저장·재열기하거나 변경을 수용·거부하여 재저장하는 시험은 수행하지 못하였다.** 이 제약이 해소되었다고 주장하지 않는다. 이번 판정은 파일에 저장된 글꼴 복구, 구조·문자 보존 및 실제 출력 검증에 한정한다. 기존 데이터·분석·문헌의 추가 확인사항도 계속 유지한다.
