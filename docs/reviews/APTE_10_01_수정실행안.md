## 2. 코드와 재분석을 먼저 고칠 항목

### 2.1. 성토 높이: 원자료의 두 범주를 복원한다

**대상:** [01_preprocess.py의 clean_cutfill](../../src/01_preprocess.py#L197)

현재 `"15M" in v and "이상" in v`는 `성토고 5M 이상 15M 미만`에도 참이다. 이 때문에 8,164건과 1,292건이 합쳐져 Table 1에 ‘15m 이상 9,456건’으로 표시됐다.

**수정 방법**

1. 공백·단위 표기를 정리한 다음 원자료 범주를 정확하게 대응시킨다. 서로 떨어진 `15M`과 `이상`의 포함 여부만으로 범주를 정하지 않는다.
2. `성토고 5M 이상 15M 미만`은 그대로 5~15m 범주로, `성토고 15M 이상`은 15m 이상 범주로 보존한다.
3. 다른 성토·절토·평지·미상 범주의 매핑도 전후 대조표로 확인한다.
4. 수정된 자료로 변수 선별, 예측 모형, SHAP, 추론용 회귀와 관련 표·그림을 다시 산출한다. 영향 없는 원자료 기반 TG 집계는 별도로 구분한다.

**확인 기준**

- 동일 원자료에서는 5~15m 8,164건, 15m 이상 1,292건으로 구분된다.
- 범주 정정만으로 전체 사고 수 83,297건이나 인명피해 사고 수 8,993건이 바뀌지 않는다.
- 두 문자열의 분류를 확인하는 작은 회귀 테스트를 추가한다.
- 범주 수·더미 수·유의 변수 수는 새 산출물에서 읽는다. 기존의 86·71·51·54·47을 고정하지 않는다.

**논문 반영 [재분석 후 반영]**

- Table 1에 `Fill 5–<15 m`와 `Fill ≥15 m`를 구분하고 건수·백분율을 다시 계산한다.
- 성토 범주 OR, SHAP 순위, 상호작용 후보가 달라졌는지 확인한다.
- 의도적으로 두 구간을 합칠 연구상 근거가 있다면 실제 범위인 ‘5m 이상’으로 정의해야 한다. 오류를 감추기 위한 사후 병합은 권하지 않는다.

### 2.2. 포트홀: 표본을 임의로 삭제하지 말고 추정 대상을 명확히 한다

**대상:** [04_confirmatory_stats.py](../../src/04_confirmatory_stats.py#L78), [06_regression_tables.py](../../src/06_regression_tables.py#L119)

현재 구현은 `주사고원인_포트홀` **열만 제거하고 986행은 유지**한다. 따라서 주사고원인의 기준효과를 과속과 포트홀이 공유한다. 두 범주의 위험이 같다고 확인한 결과가 아니라, 모형에 부과한 제약이다.

**수정 원칙**

| 선택 | 필요한 조치 | 해석과 한계 |
|---|---|---|
| 현재 추정 구조 유지 | 기준집단을 ‘과속·포트홀 합동 기준집단’으로 명시하고 처리 근거·제약·민감도 결과 보고 | 기존 표본을 보존하지만 순수한 ‘과속 대비 OR’는 아님. 이름만 바꾸면 제약의 타당성이 해결되는 것은 아님 |
| 두 범주를 분리하고 순수 과속 대비 추정 유지 | 포트홀 열을 복원하고 분리에 대응하는 추정 방법을 검토·적용한 뒤 계수·CI·검정 재산출 | 통상적인 최대우도 로지스틱에 열만 다시 넣고 끝내면 안 됨. 음이항도 별도로 추정 가능성 점검 |
| 포트홀 986행 제외 | 연구 대상을 ‘주사고원인이 포트홀인 사고를 제외한 사고’로 제한하고 회귀 표본·결과 재산출 | 표본과 해석 대상이 바뀜. 전체 분석의 자동 수정안으로 채택하지 말고 우선 민감도 분석으로 활용 |

**권고:** 전체 사고를 유지하려는 연구 목적을 우선한다. 현재 추정 구조를 사용할 경우 합동 기준집단과 제약을 공개하고, 986행 제외 결과를 민감도 분석으로 병기한다. 과속과 포트홀에 같은 효과를 부여할 근거가 부족하거나 민감도가 크면 추정 방법을 재설계한다. 순수한 과속 대비 해석이 연구의 핵심이면 두 번째 방안이 필요하다.

**현재 구조를 유지하는 경우의 방법 문장 [조건부 사용]**

> 주사고원인이 포트홀인 사고에서는 인명피해가 관측되지 않아 해당 범주의 회귀계수를 통상적인 최대우도 방법으로 추정하기 어려웠다. 본 분석에서는 해당 사고를 자료에 유지한 채 포트홀 더미를 제외하였다. 이에 따라 주사고원인 변수에서 과속과 포트홀은 동일한 기준효과를 갖도록 제약되며, 해당 변수의 오즈비는 이 합동 기준집단에 대한 비교로 해석한다.

**민감도 분석을 실제 수행한 뒤 추가할 문장 [재분석 후 반영]**

> 이 처리에 대한 민감도를 확인하기 위해 주사고원인이 포트홀인 사고를 제외한 모형을 별도로 적합하였다. 주요 추정치의 변화는 부록 [표 번호]에 제시하였다. 이 모형의 결과는 포트홀 사고를 제외한 표본에 한정하여 해석하였다.

**확인 기준**

- Table 3의 주사고원인 기준범주 표기와 실제 설계행렬이 일치한다.
- 상호작용 검정과 음이항에서도 적용한 처리를 각각 적는다.
- 로지스틱의 분리 대응법이 음이항에도 그대로 적용된다고 가정하지 않는다. 음이항에서 전부 0인 범주의 처리와 추정 안정성을 별도로 점검하고, 설계행렬이 바뀌면 포아송 적합과 α도 다시 계산한다.
- 두 회귀의 부호 일치율은 표본과 기준범주가 같은 조건에서 비교한다. 조건이 다르면 그 차이를 밝힌다.
- `주사고원인_포트홀`과 `사고시도로환경_포트홀`을 혼동하지 않는다. 후자는 1,317건 중 인명피해 3건으로, 현재 모형에 남아 있다.
- 기존 검토의 행 제외 민감도는 수정 전 성토 코딩에 기반한다. 최종 분석 조건에서 다시 계산한다.

### 2.3. 예측 평가: 분할·변수 선택·재표집·임계값 결정 순서를 바꾼다

**대상:** [01_preprocess.py의 변수 선별](../../src/01_preprocess.py#L491), [02_model_xgboost.py](../../src/02_model_xgboost.py#L102)

현재 문제는 전체 정답을 이용한 변수 선별, 평가자료에서의 임계값 선택, 비교 모형별 평가자료 차이다. 언더샘플링이라는 방법 자체를 오류로 설명하지 않는다.

**권장 절차 [재분석 후 반영]**

```text
결과 정보를 사용하지 않는 범주 표기 정정
→ 원래 인명피해 비율을 유지한 층화 학습·검증·평가 분할
→ 학습자료에서 결측 대체값·변수 선택·인코딩 규칙 확정
→ 언더샘플링 또는 합성 표본 생성은 학습자료에만 적용
→ 검증자료로 하이퍼파라미터·조기 종료·임계값 결정
→ 설정을 고정한 후 같은 평가자료에서 모든 비교 모형 평가
→ 분할 ID, 시드, 표본 수, 선택 설정, 평가 결과 저장
```

- 기존 5회 구조를 유지한다면 시드별로 동일한 평가 사고를 모든 비교 모형에 적용한다. 검증·평가자료는 자연 비율을 유지한다.
- 가중치는 해당 학습자료의 클래스 수로 계산한다.
- SMOTEN을 사용할 경우 학습자료의 원변수별 범주를 유지한 표현에 적용하고, 합성 후 모형 입력용 원-핫 인코딩을 수행한다. 하나의 원변수에서 나온 더미들을 서로 독립된 명목변수처럼 합성하지 않는다. [SMOTEN 공식 문서](https://imbalanced-learn.org/stable/references/generated/imblearn.over_sampling.SMOTEN.html)
- 변수 개수 등 선택 규칙을 미리 정하고, 성능을 보고 유리하게 고르지 않는다. 분할마다 선택 변수가 달라지면 그 차이를 기록한다.
- F1 임계값을 조정할 경우 같은 선택 기준을 비교 모형에 적용한다. 임계값 0.5 결과와 검증자료에서 선택한 임계값 결과를 구분해 보고할 수 있다.
- `y_test`는 최종 성능 계산에만 쓴다. 테스트 F1을 최대로 하는 임계값 0.61과 F1=0.352를 독립 평가 결과로 유지하지 않는다.
- 이미 전체 자료와 기존 평가 결과를 살펴본 이력이 있으므로, 재분할 결과를 ‘한 번도 보지 않은 외부 자료 검증’으로 표현하지 않는다. 재분석은 내부 평가 절차를 개선한 결과다.
- 같은 자료에서 설명과 후보 탐색을 계속 수행한다면, 회귀 검정을 독립적인 확증으로 부르지 않는다. 독립 확증을 주장하려면 탐색에 쓰지 않은 자료에서 별도로 검정해야 한다.

변수 선택과 학습된 전처리는 학습자료 안에서 수행하고, 임계값은 최종 평가자료와 분리해 선택한다. [scikit-learn 자료 누출 안내](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage), [임계값 선택 안내](https://scikit-learn.org/stable/modules/classification_threshold.html)

**방법 문장 [위 절차를 실제 수행한 뒤 사용]**

> 원래의 인명피해 사고 비율을 유지하여 자료를 학습·검증·평가 자료로 층화 분할하였다. 자료에서 추정하는 전처리 규칙과 변수 선별은 학습자료에서 수행하였으며, 불균형 처리를 위한 재표집도 학습자료에만 적용하였다. 하이퍼파라미터와 분류 임계값은 검증자료에서 결정하였고, 비교 모형들은 동일한 평가자료에서 평가하였다. 이 절차를 [반복 횟수]회 반복하여 성능의 평균과 표준편차를 제시하였다.

**확인 기준:** 학습·검증·평가 ID 중복 없음, 재표집 산출물의 출처가 학습 ID에 한정됨, 평가 정답이 변수·모형·임계값 선택에 사용되지 않음, 모형 간 평가 ID 일치.

### 2.4. SMOTEN과 격자 탐색: 재현할 수 있는 범위만 보고한다

SMOTEN AUC 0.724/F1 0.617의 생성 코드와 시드별 결과는 확보하지 못했다. `hyperparam_grid.csv`는 있지만 생성 절차와 평가자료의 역할을 확인하지 못했다.

1. 원 실행 기록을 확보하거나 2.3의 동일 평가 설계에서 다시 실행한다.
2. 하이퍼파라미터 후보·선택 지표·시드·학습/검증/평가 수·선택 결과를 표로 남긴다.

### 3.5. 상호작용 후보 A/B — p7 [조건부 사용]

대칭 SHAP 상호작용 행렬의 두 범주에 해당하는 원소를 \(I_{AB}\), 두 범주가 함께 관측된 표본집합을 \(S_{AB}\)라고 정의한다. 현재 구현은 다음과 같다.

\[
A_{AB}=\frac{1}{N}\sum_{i=1}^{N}|I_{AB}^{(i)}|,
\qquad
B_{AB}=\frac{2}{|S_{AB}|}\sum_{i\in S_{AB}}|I_{AB}^{(i)}|.
\]

> 상호작용 탐색 표본 전체에서의 절댓값 평균을 기준 A로, 두 범주가 동시에 관측된 사례에서의 절댓값 평균에 2를 곱한 값을 기준 B로 정의하였다. 기준 B는 동시 관측이 30건 이상인 쌍에 대해 계산하였다. 각 기준의 상위 15개를 합치고 중복을 제거하여 후보를 구성하였다. 동일한 원변수에서 생성된 범주 쌍은 후보에서 제외하였다.

현재는 15+15−6=24개이며, 전체 자료의 동시 관측 100건 기준 및 분리 여부를 점검한 뒤 24개를 검정했다. BH 보정 후 13개가 유의했다. 이 수는 재분석 후 갱신한다. A와 B의 배율이 다르므로 두 지표의 수치를 같은 척도처럼 직접 비교하지 않는다. 배율을 통일하기로 바꾸면 정의·표·그림 값도 함께 갱신한다.

### 3.6. 상호작용의 의미 — p8·12·15 [즉시 수정]

‘위험이 각 효과의 합보다 커진다’는 표현을 다음으로 바꾼다.

> 상호작용 계수 γ는 로그오즈 척도에서 두 주효과의 합에 더해지는 항이다. 양의 계수는 양의 추가 기여를, 음의 계수는 음의 추가 기여를 나타낸다. 양의 상호작용만으로 해당 결합 조건의 인명피해 확률이 기준집단보다 높다고 해석할 수는 없다.

결합 조건의 오즈비는 **같은 상호작용 모형**에서 비교할 두 조건을 지정하고, 다른 공변량을 동일하게 둔 설계행렬 대비 \(\exp[(x_{\text{결합}}-x_{\text{비교}})^T\theta]\)로 계산한다. 두 대상 범주가 모두 비기준 더미이고 비교 조건에서 A=B=0인 경우에는 \(\exp(\beta_A+\beta_B+\gamma)\)로 단순화된다. 기준범주가 포함된 후보에는 이 단순식을 일괄 적용하지 않는다. 신뢰구간은 같은 대비와 계수들의 공분산을 사용해 계산한다. 주효과만 있는 Table 3의 계수와 Table 4의 γ를 섞어 계산하지 않는다.

### 3.7. 음이항 정의와 추정 — p8 [즉시 수정, 수치는 재분석 후]

> \(Y_i\)는 사고 i의 사상자 수이며, \(\mu_i=E(Y_i\mid X_i)\)는 공변량이 주어졌을 때의 조건부 기대 사상자 수이다. \(\exp(\beta_j)\)는 다른 공변량을 동일하게 둘 때 해당 범주의 기대 사상자 수가 기준범주의 몇 배인지를 나타낸다.

포아송 적합 평균을 \(\hat\mu_{P,i}\)로 구분해 실제 과산포 계산식을 제시한다.

\[
\hat\alpha=\max\left\{0.01,
\frac{\sum_i[(y_i-\hat\mu_{P,i})^2-\hat\mu_{P,i}]}{\sum_i\hat\mu_{P,i}^{2}}
\right\}.
\]

> NB2 최대우도 적합의 수렴 및 표준오차 계산 상태를 점검한 뒤, 필요한 경우 포아송 적합값을 이용한 위 모멘트 추정량으로 과산포 모수를 계산하였다. 이 값을 고정한 GLM 음이항 모형에서 계수와 표준오차를 산출하였다. 따라서 표준오차와 p값은 α가 고정되었다는 조건에 따른다.

최종 실행에서 어떤 분기가 사용됐는지 명확히 적는다. 현재 결과는 고정 α 분기이며 α=3.4338328130이다. 0.01 하한은 구현 설정으로 구분하고, ‘0명 사고가 많아서 MLE가 실패했다’는 원인 단정은 피한다. 노출량 보정이 없으므로 IRR를 교통량당 사고율의 비로 설명하지 않는다.

### 3.11. 노면잡물 방향 변화 — p16 [즉시 수정]

> 변수 구성과 전처리 방식이 다른 이전 분석에서는 노면잡물의 SHAP 기여 방향이 다르게 나타났다. 다만 여러 분석 조건이 동시에 달라졌으므로, 이 차이를 특정 변수의 포함 효과로 단정하기는 어렵다.

사고 후 변수의 영향이라고 주장하려면 같은 표본·분할·설정·SHAP 방향 정의에서 해당 변수의 포함 여부만 바꾸는 추가 비교가 필요하다. 관측 비율 1.1%만으로 조정된 회귀계수나 SHAP의 양의 부호를 오류라고 판단하지 않는다. 사고 발생 자체에 대한 분석을 하지 않았으므로 ‘사고를 일으키지만 인명피해를 키우지는 않는다’는 인과 구분도 삭제한다.

### 3.12. 정책·기제·연구 의의 — p15~16 [즉시 수정]

| 현재 주장 방향 | 권장 문장 |

사고 자료만으로 계산한 비율에는 비사고 차량의 통행량이 분모로 들어가지 않는다. ‘사고 발생 위험’과 ‘사고가 기록된 경우의 인명피해 비율’을 구분한다. 눈·습기와 감속의 관계, 강설량과 사고 당시 기상의 차이에 관한 기존 한계는 유지한다.

### 3.13. 탐색과 검정의 비독립성 — p7·16 [즉시 수정]

절 제목 `확인적 통계 검정`은 현 설계를 유지한다면 **`회귀모형을 이용한 통계적 검토`**로 완화하는 것을 권한다.

> 상호작용 후보의 탐색과 회귀 검정에 사용한 자료가 독립적이지 않으므로, 회귀 검정 결과는 독립 자료에서 재현된 확증으로 해석하지 않았다. 후보 내 다중검정에는 BH 보정을 적용했으나, 이 보정만으로 자료 기반 후보 선택에 따른 불확실성이 해소되지는 않는다.

새 자료에서 재현하지 않은 결과를 ‘최종 검증된 위험요인’으로 단정하지 않는다. 이 한계는 기존 PDF에도 일부 있으므로 삭제하지 않고 방법·결론의 표현을 맞춘다.

[statsmodels 정의](https://www.statsmodels.org/stable/generated/statsmodels.discrete.discrete_model.LogitResults.prsquared.html), [McFadden 저자 공개본](https://eml.berkeley.edu/reprints/mcfadden/quant_methods.pdf)
